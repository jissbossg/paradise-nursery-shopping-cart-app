# Paradise Nursery: Una Experiencia de Compra Reactiva y Dinámica

Bienvenido a **Paradise Nursery**, una aplicación de carrito de compras para una tienda de plantas en línea. Este proyecto demuestra el uso de React y Redux Toolkit para crear una experiencia de comercio electrónico funcional, con gestión de estado global para el carrito, navegación entre páginas y una interfaz de usuario intuitiva.

## Características
- **Catálogo de Plantas:** Muestra al menos 6 plantas de interior únicas por categoría (mínimo 3 categorías).
- **Carrito de Compras:** Añade, elimina y ajusta cantidades de productos.
- **Estado Global:** Gestionado con Redux Toolkit (`CartSlice.jsx`).
- **Navegación:** Barra de navegación persistente con contador de ítems en el carrito.
- **Página de Inicio:** Landing page con botón "Comenzar" para ir al catálogo.
- **Página "Sobre Nosotros":** Información de la empresa.

## Tecnologías
- React 18
- Redux Toolkit
- React-Redux
- Vite
